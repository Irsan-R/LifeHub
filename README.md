# LifeHub

## Today UI preview

This repository includes a responsive Today Dashboard implementation. Run `npm install`, `npm run dev`, then open `/today?demo=1` to see isolated preview data. `/today` intentionally shows the unavailable state until canonical APIs and authentication are connected.

Run `npm run build` and `npm test` for type/build and browser checks. The browser check uses local Chrome and a running server (`npm run start`). See [Today implementation review](docs/design/today-implementation-review.md) for screenshots and known design limitations.
